# Phase 3 report — 2026-09-26 (Themes / SEO / Listings)

## 1. Status

**Built and tested: three themes, listings management with photos, CSV import and feeds, the
full-page cache with `site:regenerate --all`, per-tenant SEO, and the Lighthouse / Playwright
gates.** An agent now picks atlas, marina or palm in the wizard and gets a site that renders
every page in both directions from one config; adds listings from the phone (multi-photo, drag
order, AED, community autocomplete, map pin), from a CSV with a template and row errors, or from
a feed (Generic XML, Property Finder) that syncs every 30 minutes with per-agent filters; the
site is served from a cache that is purged on every change and rebuilt in bulk after a deploy;
each site publishes its own `sitemap.xml`, `robots.txt`, canonical + hreflang, Open Graph and
schema.org data. Lighthouse on a mobile profile passes the §10 thresholds on the three themes in
both locales (§4); Playwright drives the themes, the SEO surface, the cache and the whole
listings flow on a 375×667 Chromium.

Phase 0's server steps are still pending (§6), unchanged.

## 2. What was built

  entry each, the eight pages and twelve sections, six palettes, RTL; marina = split hero and
  horizontal listing rows, palm = editorial type, hairlines, gold accent, testimonials right after

  LCP image; `x-site.section-heading` takes `level="1"` so every page has one `h1`. Dark mode only

- **Listings (§14)** — `app/Livewire/Listings/{Index,Form,Import,Feeds}` on the app host (search,

- **Full-page cache (§16)** — `app/Caching/{PageCache,PurgesSitePages,SiteWarmer,Regenerator}`,

works on every store, one write to purge); listings that leave a feed are hidden, not deleted

## 5. Risks and known gaps

- **Lighthouse numbers are from this container** (simulated throttling on a shared CPU): the
  performance score moves a few points between runs; the gate is ≥ 90 and the lowest observed
  is in the table. The first run on the production stack (HTTP/2, Brotli, real CDN cache headers)
  is what fixes the numbers.
- **Feeds are tested against fixture XML**, not a live Property Finder export; the adapter
  follows the documented export and every field it does not carry stays empty.
- **`max-age=60`** means a visitor's browser may show a page for up to a minute after an edit
  (the ETag revalidates after that); the agent's own "View on my site" link is affected the same way.
- **Queue is `sync` locally**; `RegenerateBatch`, `SyncFeed` and `WarmCache` get their first
  Horizon run at bootstrap. `regenerate --all` on 1000 sites is extrapolated from 213 (§4).
- **Custom domains are still Phase 4**: sitemap and canonical use the primary host, which is the
  subdomain until then.
