## 2. How to verify

```sh
cd agentsites/app && composer install && npm ci && npm run build
vendor/bin/pint --test && vendor/bin/phpstan analyse            # clean, 0 errors
vendor/bin/pest --coverage --min=90                              # 84 tests, 560 assertions, 92.2 % on the gated dirs
```

Acceptance test A1 in the test environment (`tests/Feature/Console/SiteCommandsTest.php`):
`platform:site:create --name "Ahmed Al Falasi" --whatsapp +971501234567` → `status: live`,
`https://ahmed-al-falasi.{base}/`, and a GET on that host returns 200 in `en` and `ar` with the
agent's name, generated copy and demo listings — in the same process, with no restart. On the
server: `make site NAME="…" WHATSAPP=+9715…` after `infra/scripts/bootstrap.sh`.

Other checks: `docs/ADD-SITE.md` lists every command; `make test` runs the local gates.

## 6. Risks and known gaps

- **Not yet run on a server.** `bootstrap.sh`, `deploy.sh`, `build-assets.sh` and the compose
  stack have been validated statically and piece by piece (Caddyfile with a real Caddy build,
  compose config, the app against real PostgreSQL) but never together on a box. The first
  bootstrap will surface small fixes; nothing in it touches the legacy platform.
- **Redis untested end to end**: tests use the array cache/sync queue; the code paths are store
  agnostic, but Horizon and the Redis host cache get their first real run at bootstrap.
- **Coverage of `app/Domains` and `app/Billing` is empty** (no code yet); the gate widens as
  Phase 4/5 add them.
- **Design of atlas is functional, not yet art-directed**; Lighthouse ≥ 90/95/95 is a Phase 3 gate.
- Route caching bakes the platform hosts (derived from `.env`) into `bootstrap/cache/routes`;
  `platform:domain:change` (Phase 7) must re-run `optimize`, which is already what `deploy.sh` does.
- The `paperclips` repository remains public; nothing sensitive is in the tree, but D5 stands.

## 7. Blockers (unchanged from Phase 0)

1. **Server access** — run `make discover BASE=<domain>` and `make pre-platform-backup` on the
   server, or give this environment SSH + network access; then `infra/scripts/bootstrap.sh`.
2. **DNS on Cloudflare + API token** — needed for the wildcard certificate; steps in the Phase 0 report.
3. **Approve D1–D5, create the private repository, set the CI variable `PLATFORM_BASE_DOMAIN`.**
