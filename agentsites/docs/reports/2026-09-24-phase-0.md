## 7. Blockers (each with a recommended default)

1. **Server access.** The build environment cannot SSH to the server, and its network policy
   blocks DNS/HTTPS to `{base}`. *Default:* you run, on the server, `make discover BASE={base}`
   and `make pre-platform-backup` (with `OFFSITE_RCLONE_REMOTE` or `OFFSITE_SSH_TARGET` set) from
   a checkout of this branch, and paste `discovery-<date>.md` plus the backup's `COMPLETE`
   lines back; Phase 0 then closes in one pass. Alternative: allow the hosts `{base}`,
   `cloudflare-dns.com` in the environment's network policy and give the environment an SSH key.
2. **DNS on Cloudflare + the Cloudflare token.** Unknown until `dig +short NS {base}` is
   answered. *Default:* if the nameservers are not `*.ns.cloudflare.com`, move the zone now:
   (1) Cloudflare → Add a site → `{base}` → Free plan; (2) check the imported records against
   `dig` for A/AAAA/MX/TXT (mail must keep working) and set every record that this platform will
   serve to DNS-only (grey cloud — an orange cloud breaks DNS-01 origin issuance and custom-domain
   verification); (3) at the registrar, replace the nameservers with the two Cloudflare shows;
   (4) wait for "Active"; (5) My Profile → API Tokens → Create Token → template "Edit zone DNS"
   → Zone Resources: Include → Specific zone → `{base}` → copy into `CLOUDFLARE_API_TOKEN`;
   (6) add `A {base}` and `A *.{base}` pointing at the server (DNS-only). Nothing else changes
   for the legacy site.
3. **Approval of D1–D5 and the repository home.** *Default:* approve as proposed and create an
   empty private repository (e.g. `agentsites`); I move the tree there with history.
